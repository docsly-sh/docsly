This page showcases the MDX components you can use when writing documentation.

## Headings

Use `##` for sections and `###` for subsections. Each heading automatically appears in the table of contents on the right.

## Text formatting

You can use **bold**, _italic_, and `inline code`. Links work too — like [Fumadocs](https://fumadocs.dev).

## Lists

Unordered list:

- First item
- Second item
- Third item

Ordered list:

1. Step one
2. Step two
3. Step three

## Code blocks

```bash
pnpm install
pnpm dev
```

```tsx title="components/example.tsx"
export function Example({ title }: { title: string }) {
  return <h1>{title}</h1>;
}
```
